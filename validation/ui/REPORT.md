# GNSS Caster 3.2.0 — проверка двух языков

Дата: 2026-10-14. Версия подготовлена для публикации; на Raspberry Pi не установлена.

## Результат

Все страницы React + Material UI, вход и 2FA поддерживают English / Русский. Выбор языка находится в шапке и на экране входа, сохраняется в браузере и не сбрасывает введённые значения форм. Форматирование дат, чисел и элементы Material UI следуют выбранному языку.

В настройках уведомлений добавлен отдельный язык Telegram-бота. Он сохраняется в БД, доступен администратору и применяется к следующим сообщениям без перезапуска. Проверены русские кнопки, справка, ответы и уведомления, сохранение идентификаторов команд и пользовательских имён. Реальные сообщения в Telegram не отправлялись.

Установщик теперь называется `gnss-caster-install.sh`; прежнее имя содержало устаревший номер 3.0.1. Внутренняя версия и `--version` — 3.2.0. Сборка встроена в установщик: Node.js и CDN на устройстве не нужны.

Затем добавлена и проверена защита словаря от совпадений с именами свойств JavaScript; сборка обновлена. Проверки встроенной сборки повторены после последнего встраивания.

## Ограничения

Предпросмотр использует тестовые данные и не обращается к рабочему caster. Операции записи в браузерных тестах подменены; системные службы и Bluetooth в регрессионных тестах используют тестовые зависимости. Исходные технические журналы и ответы оборудования сохраняются без перевода.

Рабочий caster не обновлялся и не перезапускался; наблюдение за полевыми работами не возобновлялось. Последняя подтверждённая на устройстве версия — 3.0.12. Устранение первоначального зависания Bluetooth на оборудовании пока не доказано.

Следующий эксплуатационный этап — установка вне полевых работ с актуальной резервной копией, затем вход/2FA, права, оба языка, пробное уведомление Telegram, загрузка и проверка архива через nginx и реальный поток поправок. Настоящее восстановление требует отдельного согласованного действия. План: [REPAIR_TEST_PLAN.md](../../REPAIR_TEST_PLAN.md).
